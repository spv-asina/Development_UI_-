# Разработка пользовательского интерфейса

Лабораторная работа по дисциплине «Разработка пользовательского интерфейса». СПбПУ, 2025–2026.

## Этапы

| Этап | Платформа | Стек |
|------|-----------|------|
| 1 | Десктопное приложение | Python, Tkinter, PyYAML |
| 2 | Веб-приложение | Python, Streamlit, PyYAML |

## Задание

Реализация симуляции «Робот-химик» — программа управляет роботом в лабиринте химической лаборатории. Робот собирает реактивы, обходит препятствия и находит путь к цели.

Входные данные — YAML-маппинг классов и перечислений (UML-диаграмма), на основе которого строится доменная модель.

## Запуск

```bash
# Этап 1 (десктоп)
pip install pyyaml
python desktop.py

# Этап 2 (веб)
pip install streamlit pyyaml
streamlit run web.py
```
